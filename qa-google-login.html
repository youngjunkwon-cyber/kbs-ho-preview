화면은 라이브 FO(2026-10-26)를 그대로 떠 왔고, 분홍 점선(새 요소 표시)이 이번에 더하는 부분입니다. 로그인한 My Page와 예약자 정보의 전화번호 입력칸(Use a different number 상태)도 라이브에서 떠 왔고 이름·연락처는 예시값입니다. 스토어 목록에서는 DDYOU만 눌립니다.
화면 문구는 라이브 FO 번역 문구를 그대로 썼습니다. 라이브 탈퇴는 실제로 누를 수 없어 번역 문구만 근거로 했고, Still Want to Withdraw? 다음에 본인 확인 창(비밀번호 또는 구글)을 넣었습니다(전달 문서 라-6). "Incorrect password."는 라이브에 없어 새 문구입니다. 라이브 문구 여부는 STG FO 페이지에 심긴 번역 묶음에서 확인했습니다(Still Want to Withdraw?, Delete Membership, Login failed. Please try again. 모두 있음). 닉네임 단어 목록(6개 언어)은 시안용 임시입니다. 닉네임 중복 안내는 라이브에 문구가 없어 "This nickname is already in use."를 새로 넣었습니다.
구글 화면(계정 선택·앱 안 로그인)은 구글이 그리는 화면을 흉내만 냈습니다. 코드 입력 단계는 라이브(STG) 모양 그대로 넣었고 시안에서는 코드 123456만 맞는 코드입니다. 코드로 인증한 가입과 구글로 인증한 가입 모두 Sign Up까지 동작합니다. 안내 메일은 보내지 않습니다(결정).
