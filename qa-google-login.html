시드 데이터
회원 1 verified@example.com (이메일 인증 완료, 비밀번호 pass1234) / 회원 2 unverified@example.com (미인증, pass1234) / 회원 3 googleonly@gmail.com (구글로 가입, 비밀번호 없음) / 회원 5 linked@example.com (이메일 가입 + 구글 연결, pass1234)
기기의 구글 계정: Alex Kim(새 사람) / 이름 없음 / Mina Park(회원 1 이메일) / Mina Park(회원 1 이메일 대문자) / Old User(회원 2) / Jane Doe(회원 3) / Both Ways(회원 5) / Other Person(어느 회원과도 다른 이메일)

확인하지 않는 것
화면은 라이브 FO(2026-10-26)를 그대로 떠 왔고, 분홍 점선(새 요소 표시)이 이번에 더하는 부분입니다. 로그인한 My Page와 예약자 정보의 전화번호 입력칸(Use a different number 상태)도 라이브에서 떠 왔고 이름·연락처는 예시값입니다. 스토어 목록에서는 DDYOU만 눌립니다.
화면 문구는 라이브 FO 번역 문구를 그대로 썼습니다. 라이브 탈퇴는 실제로 누를 수 없어, 번역 문구에 비밀번호 단계가 없는 것을 근거로 Still Want to Withdraw? 다음 바로 탈퇴로 넣었습니다. 닉네임 단어 목록(6개 언어)은 시안용 임시입니다. 닉네임 중복 안내는 라이브에 문구가 없어 "This nickname is already in use."를 새로 넣었습니다.
구글 화면(계정 선택·앱 안 로그인)은 구글이 그리는 화면을 흉내만 냈습니다. 인증 코드 발송과 가입 나머지 단계는 동작하지 않습니다. 안내 메일은 보내지 않습니다(결정).
