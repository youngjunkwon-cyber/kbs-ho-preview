외부 위젯 빌더 Elfsight에서 매장의 구글 리뷰 위젯을 만들고, 발급된 임베드 코드를 어드민 스토어 정보 · 리뷰 설정에 삽입하여 스토어 상세에 노출하는 전체 절차를 안내합니다.

01
PART 01
위젯 생성 (Elfsight)
Elfsight에서 구글 리뷰 위젯을 만들고 임베드 코드를 발급받습니다.
1-1
Elfsight 로그인
elfsight.com · 운영팀 공용 계정
SCREENSHOT · Elfsight 로그인 화면
운영팀 공용 계정으로 Elfsight에 로그인합니다.
  • 1https://elfsight.com/ 접속
  • 2dev 계정으로 로그인 — 아이디 dev@eightint.io / 비밀번호는 운영팀 별도 공유
⚠️ 공용 계정 비밀번호는 외부에 공유·노출하지 마세요. 이 페이지에는 비밀번호를 기재하지 않습니다.
1-2
위젯 생성 시작
Create Widget → 템플릿 : 목록
SCREENSHOT · Create Widget / 템플릿 선택
새 위젯을 만들고 시작 템플릿을 선택합니다.
  • 1[Create Widget] 클릭
  • 2구글 리뷰 위젯 템플릿 중 목록 선택
💡 위젯 이름은 매장 식별이 쉽도록 스토어명으로 지정해 두면 이후 관리가 편합니다.
1-3
업체 검색 및 연결
매장의 구글 비즈니스 연결
SCREENSHOT · 업체 검색 및 연결
위젯에 표시할 리뷰의 출처인 매장의 구글 비즈니스를 검색해 연결합니다.
  • 1매장의 구글 비즈니스명 또는 구글 지도 링크로 검색
  • 2검색 결과에서 정확한 매장을 선택해 연결
  • 3실제 리뷰가 미리보기에 불러와지는지 확인
⚠️ 동명·지점이 여러 곳일 수 있으니 주소 · 평점 · 리뷰 수를 대조해 정확한 매장이 맞는지 반드시 확인하세요.
1-4
위젯 설정 (표준값)
AI 번역 · 레이아웃 · 헤더
SCREENSHOT · 위젯 설정 화면
매장마다 위젯 형태가 제각각이지 않도록 아래 운영 표준값으로 설정합니다.
  • AI 기능
    AI로 리뷰 번역하기 ON
  • 레이아웃
    캐러셀 선택 · 열 / 행 = 1
  • 헤더 · 전체 평점
    전체 평점 ON  (제목 OFF · 평점 ON · 리뷰 수 ON)
  • 헤더 · 스타일
    스타일 = 오른쪽에서 4번째
  • 헤더 · 리뷰 작성하기
    리뷰 작성하기 OFF
📌 위 값은 운영 표준값입니다. 매장마다 동일하게 적용하고, 기준이 바뀌면 가이드를 먼저 업데이트하세요.
1-5
임베드 코드 복사
Save → Add to website → Copy
SCREENSHOT · 임베드 코드 복사
설정이 끝나면 위젯을 저장하고 임베드 코드를 복사합니다. 이 코드를 스토어 페이지에 그대로 붙여넣게 됩니다.
  • 1[Save]로 설정 저장
  • 2[Add to website] → 임베드 코드 패널 열림
  • 3[Copy] 버튼으로 코드 전체 복사 (script + div 두 줄)
<!-- Google Reviews | 강남다움의원 --> <script src="https://elfsightcdn.com/platform.js" async></script> <div class="elfsight-app-f2f77e63-7a80-4392-ac36-031716e34204" data-elfsight-app-lazy></div>
⚠️ 코드는 한 글자도 수정하지 마세요. 강조된 앱 ID·따옴표·공백이 바뀌면 위젯이 표시되지 않습니다. 반드시 [Copy] 버튼으로 전체를 그대로 복사합니다.
02
PART 02
스토어 페이지에 삽입
복사한 임베드 코드를 어드민 스토어 정보의 리뷰 설정에 붙여넣습니다.
2-1
스토어 정보 · 리뷰 설정 ON
어드민 → 스토어 정보 → 리뷰 설정
SCREENSHOT · 스토어 정보 · 리뷰 설정
어드민에서 위젯을 적용할 매장의 스토어 정보로 진입해 리뷰 설정을 켭니다.
  • 1어드민 스토어 정보 진입
  • 2리뷰 설정 ON
  • 31단계에서 위젯을 만든 매장과 동일한지 매장명으로 재확인
2-2
코드 붙여넣기 · 수/평점 입력
임베드 코드 + 리뷰 수 + 리뷰 평점
SCREENSHOT · 코드 붙여넣기 / 수 / 평점
리뷰 설정 영역에 복사한 임베드 코드를 붙여넣고, 리뷰 수와 리뷰 평점을 입력합니다.
  • 1복사한 임베드 코드 전체를 붙여넣기 (script + div 두 줄 모두)
  • 2리뷰 수 입력
  • 3리뷰 평점 입력
📌 리뷰 수 · 리뷰 평점은 위젯과 별개로 직접 입력하는 값입니다. 연결한 매장의 구글 실제 수치와 동일하게 맞춰 입력하세요.
⚠️ 코드 일부만 붙여넣으면 위젯이 뜨지 않습니다. <script> 줄과 <div> 줄이 모두 들어갔는지 확인하세요. 매장 교체 시에는 기존 코드를 모두 지운 뒤 새 코드를 넣습니다.
2-3
저장 및 노출 확인
[저장] → FO 스토어 상세 확인
SCREENSHOT · FO 스토어 상세 노출
저장 후 실제 스토어 상세 페이지에서 위젯이 정상적으로 노출되는지 확인합니다.
  • 1스토어 정보 [저장] 클릭
  • 2FO 해당 스토어 상세 페이지 새로고침
  • 3구글 리뷰 위젯이 평점 · 리뷰 수 · 리뷰 내용과 함께 표시되는지 확인
  • 4모바일 화면에서도 깨짐 없이 노출되는지 확인
💡 위젯이 안 보이면 ① 코드가 일부만 들어갔는지 ② 다른 매장 코드와 바뀌지 않았는지 ③ Elfsight에서 위젯이 저장(Save)됐는지 순서로 점검하세요.
⚠️ 위젯 첫 로딩은 몇 초 지연될 수 있습니다. 즉시 안 떠도 새로고침 후 잠시 기다려 확인하세요.
