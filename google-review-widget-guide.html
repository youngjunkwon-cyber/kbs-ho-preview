Elfsight 구글리뷰 대시보드 열기 dash.elfsight.com/apps/google-reviews · 새 탭에서 열림

01
PART 01
위젯 생성 (Elfsight)
운영팀 공용 계정(dev@eightint.io)으로 Elfsight에 로그인한 뒤, 매장별 구글 리뷰 위젯을 만들고 임베드 코드를 발급받습니다.
STEP 1
위젯 생성 시작
Google Reviews → Create Widget
SCREENSHOT 1 · 위젯 목록 / Create Widget
Elfsight에 로그인한 뒤 Google Reviews 앱에서 새 위젯을 만듭니다.
  • 1Elfsight 구글리뷰 대시보드 접속 → dev 계정 로그인 (아이디 dev@eightint.io, 비밀번호는 운영팀 별도 공유)
  • 2구글 리뷰 위젯 목록 화면으로 진입
  • 3우측 상단 [Create Widget] 클릭
⚠️ 공용 계정 비밀번호는 외부에 공유·노출하지 마세요. 이 페이지에는 비밀번호를 기재하지 않습니다.
💡 위젯 이름은 매장 식별이 쉽도록 스토어명으로 지정해 두면 이후 관리가 편합니다.
STEP 2
목록 템플릿 선택
시작 템플릿 → 목록
SCREENSHOT 2 · 시작 템플릿 선택
[Create Widget]을 누르면 시작 템플릿 선택 화면이 뜹니다. 여기서 목록 템플릿을 선택합니다.
  • 1템플릿 목록에서 목록 템플릿 선택
  • 2하단 [이 템플릿으로 계속하기] 클릭
📌 시작 템플릿은 목록으로 시작합니다. 노출 형태(캐러셀)는 5단계 레이아웃에서 변경합니다.
STEP 3
소스 연결
구글맵 노출명으로 검색 → 연결
SCREENSHOT 3 · 소스 연결
좌측 [콘텐츠] · 소스 연결에서 매장의 구글맵 노출명으로 검색해 리뷰 출처를 연결합니다.
  • 1[업체명 및 주소] 입력란에 매장의 구글맵 노출명으로 검색
  • 2결과에서 정확한 매장을 선택해 연결 (주소가 없으면 구글 지도 링크 사용)
  • 3실제 리뷰가 미리보기에 불러와지는지 확인
⚠️ 동명·지점이 여러 곳일 수 있으니 주소 · 평점 · 리뷰 수를 대조해 정확한 매장이 맞는지 반드시 확인하세요.
STEP 4
AI 기능 설정
AI 생성 요약 OFF · AI 리뷰 번역 ON
SCREENSHOT 4 · AI 기능
좌측 [AI 기능] 패널에서 두 토글을 아래와 같이 설정합니다.
  • AI 생성 요약
    OFF
  • AI로 리뷰 번역하기
    ON
💡 번역은 설정의 언어 기준으로 동작하며 완료까지 시간이 걸릴 수 있습니다. 번역 중에는 페이지를 벗어나지 마세요.
STEP 5
레이아웃 설정
캐러셀 · 열 1 · 행 1
SCREENSHOT 5 · 레이아웃
좌측 [레이아웃] 패널에서 노출 형태를 캐러셀로 바꾸고, 열·행을 각각 1로 맞춥니다.
  • 레이아웃
    캐러셀로 변경
  • 열
    1
  • 행
    1
STEP 6
헤더 / 스타일
스타일 우측 4번째 · 제목 OFF · 리뷰 작성하기 OFF
SCREENSHOT 6 · 헤더 / 스타일
좌측 [헤더] 패널에서 스타일과 표시 요소를 아래 표준값으로 설정합니다.
  • 스타일
    우측에서 4번째 항목으로 변경
  • 제목
    OFF
  • 리뷰 작성하기
    OFF
📌 위 값은 운영 표준값입니다. 매장마다 동일하게 적용하고, 기준이 바뀌면 가이드를 먼저 업데이트하세요.
STEP 7
Publish · 위젯 코드 발췌
Publish → Install → 위젯 코드(앱 ID) 발췌
SCREENSHOT 7 · 임베드 코드 모달
설정이 끝나면 위젯을 게시한 뒤, Install 모달의 임베드 코드에서 위젯 코드(앱 ID) 부분만 발췌합니다. 8단계 BO 리뷰 설정의 위젯 코드 칸에 넣을 값입니다.
  • 1우측 상단 [Publish] 클릭
  • 2위젯 목록(My Apps)으로 이동
  • 3해당 위젯의 [Install] 클릭 → 임베드 코드 모달 열림
  • 4코드 중 위젯 코드(앱 ID)만 발췌 — elfsight-app- 뒤의 ID 값
⚠️ 앱 ID는 공백·문자 변경 없이 그대로 발췌하세요. 한 글자라도 다르면 위젯이 표시되지 않습니다.
02
PART 02
스토어 페이지에 삽입
발췌한 위젯 코드(앱 ID)를 어드민 스토어 정보의 리뷰 설정에 입력합니다.
STEP 8
스토어 정보 · 리뷰 설정 입력
연동 · 위젯 코드 · 리뷰 수 / 평점
SCREENSHOT 8 · 어드민 리뷰 설정
어드민 스토어 정보 · 리뷰 설정 탭에서 위젯을 연동하고, 7단계에서 발췌한 위젯 코드와 리뷰 수 · 평점을 입력합니다.
  • 리뷰 위젯
    연동 선택 (미연동 → 연동)
  • 위젯 코드
    7단계에서 발췌한 앱 ID를 입력
  • 리뷰 수 추가
    구글 실제 리뷰 수 입력 (예: 233)
  • 리뷰 평점 추가
    구글 실제 평점 입력 (예: 4.9)
  • 1위 값 입력 후 [저장] 클릭
  • 2FO 스토어 상세에서 위젯 · 평점 · 리뷰 수 노출 확인 (모바일 포함)
📌 리뷰 수 추가 · 리뷰 평점 추가는 위젯과 별개로 직접 입력하는 값입니다. 연결한 매장의 구글 실제 수치와 동일하게 맞춰 입력하세요.
💡 위젯이 안 보이면 ① 리뷰 위젯이 [연동]인지 ② 위젯 코드(앱 ID)가 정확한지 ③ Elfsight에서 Publish 됐는지 순서로 점검하세요. 첫 로딩은 몇 초 지연될 수 있습니다.
