01
PART 01
위젯 생성 (Elfsight)
Elfsight에서 구글 리뷰 위젯을 만들고 임베드 코드를 발급받습니다.
1-1
Elfsight 진입 및 위젯 만들기
elfsight.com 로그인 → Google Reviews 선택
SCREENSHOT · Elfsight 위젯 생성 화면
운영팀 공용 Elfsight 계정으로 로그인한 뒤, 새 위젯을 Google Reviews 템플릿으로 생성합니다.
  • 1elfsight.com 접속 → 운영팀 공용 계정으로 로그인
  • 2대시보드에서 [Create Widget] 클릭
  • 3위젯 목록에서 Google Reviews 선택
  • 4제공되는 템플릿 중 하나로 시작 (이후 자유롭게 변경 가능)
💡 매장마다 위젯을 각각 생성합니다. 위젯 이름은 매장 식별이 쉽도록 스토어명으로 지정해 두면 이후 관리가 편합니다.
1-2
구글 비즈니스 연결
매장의 구글 비즈니스 프로필 검색 → 연결
SCREENSHOT · 구글 비즈니스 연결
위젯에 표시할 리뷰의 출처인 구글 비즈니스 프로필을 연결합니다. 매장명 또는 구글 지도 URL로 검색합니다.
  • 1설정 패널의 [Sources] / [Add source] 클릭
  • 2매장의 구글 비즈니스명 또는 구글 지도 링크를 입력해 검색
  • 3검색 결과에서 정확한 매장을 선택해 연결
  • 4실제 리뷰가 위젯 미리보기에 불러와지는지 확인
⚠️ 동명이인·지점이 여러 곳일 수 있으니, 주소·평점·리뷰 수를 대조해 정확히 해당 매장이 맞는지 반드시 확인하세요.
1-3
레이아웃 / 표시 설정
레이아웃 · 필터 · 디자인 통일
SCREENSHOT · 레이아웃 / 표시 설정
위젯의 노출 형태를 설정합니다. 매장마다 모양이 제각각이지 않도록 운영 표준값으로 통일합니다.
  • Layout
    리뷰 노출 형태. 스토어 상세에는 슬라이더(Carousel) 또는 그리드를 권장. 매장 간 동일하게 통일합니다.
  • Filter / Rating
    표시할 리뷰의 최소 평점을 설정 (예: 4점 이상). 빈 내용·저평점 리뷰가 그대로 노출되지 않도록 합니다.
  • Header / Summary
    상단의 평균 평점·총 리뷰 수·구글 로고 요약 영역 표시 여부. 신뢰도를 위해 표시 권장.
  • Language
    위젯 UI 텍스트 언어. 다국어 스토어 특성상 별도 지정이 없으면 영어(English)로 통일합니다.
  • Style / Color
    배경·폰트 등 디자인. 스토어 페이지와 이질감이 없도록 밝은 배경 기본형을 유지합니다.
📌 설정 표준값은 운영팀 내부 기준을 따릅니다. 매장별로 임의 변경하지 말고, 기준이 바뀌면 가이드를 먼저 업데이트하세요.
1-4
게시 및 임베드 코드 복사
[Add to website] → 코드 복사
SCREENSHOT · 임베드 코드 복사
설정이 끝나면 위젯을 게시하고 임베드 코드를 복사합니다. 이 코드를 스토어 페이지에 그대로 붙여넣게 됩니다.
  • 1우측 상단 [Save]로 설정 저장
  • 2[Add to website] 클릭 → 임베드 코드 패널 열림
  • 3표시된 코드를 [Copy] 버튼으로 전체 복사
<!-- Elfsight Google Reviews 위젯 (예시 형태) --> <script src="https://static.elfsight.com/platform/platform.js" async></script> <div class="elfsight-app-xxxxxxxx-xxxx-xxxx" data-elfsight-app-lazy></div>
⚠️ 코드는 한 글자도 수정하지 마세요. 따옴표·공백·앱 ID가 바뀌면 위젯이 표시되지 않습니다. 반드시 [Copy] 버튼으로 전체를 그대로 복사합니다.
💡 무료 플랜은 노출 리뷰 수·월 조회수에 제한이 있고 Elfsight 브랜딩이 표시될 수 있습니다. 제한 도달 시 운영팀에 플랜을 확인하세요.
02
PART 02
스토어 페이지에 삽입
복사한 임베드 코드를 어드민 스토어 페이지의 구글리뷰 필드에 붙여넣습니다.
2-1
스토어 관리 진입
어드민 → 스토어 관리 → 해당 매장 편집
SCREENSHOT · 스토어 관리 화면
어드민에서 위젯을 적용할 매장을 찾아 편집 화면으로 진입합니다.
  • 1어드민 스토어 관리 메뉴 진입
  • 2적용할 매장 검색 후 행 선택 → 편집 화면 진입
  • 31단계에서 위젯을 만든 매장과 동일한지 매장명으로 재확인
2-2
구글리뷰 필드에 붙여넣기
[구글리뷰] 전용 입력 필드
SCREENSHOT · 구글리뷰 입력 필드
스토어 편집 화면의 구글리뷰 전용 입력 필드에 복사한 임베드 코드를 붙여넣습니다. 본문 에디터가 아닌 별도 필드입니다.
  • 1구글리뷰 입력 필드를 찾는다
  • 2필드를 비우고 1-4에서 복사한 임베드 코드 전체를 붙여넣기
  • 3script와 div 두 줄이 모두 들어갔는지 확인
⚠️ 코드 일부만 붙여넣으면 위젯이 뜨지 않습니다. <script> 줄과 <div> 줄이 모두 포함됐는지 확인하세요.
📌 이미 위젯이 들어간 매장을 교체할 때는, 기존 코드를 모두 지운 뒤 새 코드를 붙여넣습니다. 두 코드가 섞이면 위젯이 중복 표시됩니다.
2-3
저장 및 노출 확인
[저장] → FO 스토어 상세에서 확인
SCREENSHOT · FO 스토어 상세 노출
저장 후 실제 스토어 상세 페이지에서 위젯이 정상적으로 노출되는지 확인합니다.
  • 1편집 화면 [저장] 클릭
  • 2FO 해당 스토어 상세 페이지를 새로고침
  • 3구글 리뷰 위젯이 정상 평점·리뷰 내용과 함께 표시되는지 확인
  • 4모바일 화면에서도 깨짐 없이 노출되는지 확인
💡 위젯이 안 보이면 ① 코드가 일부만 들어갔는지 ② 다른 매장 코드와 바뀌지 않았는지 ③ Elfsight에서 위젯이 게시(Save) 상태인지 순서로 점검하세요.
⚠️ 위젯 첫 로딩은 몇 초 지연될 수 있습니다. 즉시 안 떠도 새로고침 후 잠시 기다려 확인하세요.
