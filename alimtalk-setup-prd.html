알림톡 템플릿 6종 (STG) 발송 시점 템플릿 코드 ------------------------------------------------------ 고객 예약 접수 완료 PRD_HOST_BKG_NEW 방문 24시간 전 PRD_HOST_BKG_SOON 미확인 예약 리마인드 (접수 후 1시간) PRD_HOST_BKG_UNCK 예약 취소 (고객·매장·관리자) PRD_HOST_BKG_CNCL 고객 변경 신청 PRD_HOST_BKG_CHRQ 변경 수락 완료 PRD_HOST_BKG_CHOK 변수 매핑 ------------------------------------------------------ visit_date 방문일 YYYY-MM-DD visit_day 방문 요일 한 글자 (월~일) visit_time 방문 시각 HH:mm (KST) new_date 변경 후 방문일 YYYY-MM-DD new_day 변경 후 요일 한 글자 new_time 변경 후 시각 HH:mm old_date 변경 전 방문일 YYYY-MM-DD old_day 변경 전 요일 한 글자 old_time 변경 전 시각 HH:mm nationality 국적 한글명 (대한민국, 대만, 일본 …) customer_name 여권 영문명, 14자 초과 시 자름 booking_number 예약번호 13자리 cancelled_by '고객' 또는 '매장' 템플릿별 사용 변수 ------------------------------------------------------ NEW / SOON / UNCK visit_date, visit_day, visit_time, nationality, booking_number CNCL visit_date, visit_day, visit_time, nationality, booking_number, cancelled_by CHRQ / CHOK new_date, new_day, new_time, old_date, old_day, old_time, customer_name, booking_number 주의 ------------------------------------------------------ - 요일은 '월' 한 글자만 넘겨주세요. 괄호는 템플릿에 고정입니다 - 국적은 영문 원문이 아니라 한글명입니다 - 버튼 링크가 예약번호를 받습니다. HOST 에서 예약번호로 해당 예약을 열 수 있어야 합니다 - 버튼 링크 도메인이 환경별로 달라 템플릿도 환경별로 따로 등록합니다 - 이 문서는 운영 등록용입니다. 스테이징은 앞을 STG_ 로 바꾸고 링크를 k-beautystation-host.vercel.app 으로 등록합니다
