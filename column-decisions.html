칼럼(원장 칼럼) 기능 — 결정 요청

입점사(원장)가 자기 매장 페이지에 직접 글(시술·진료 정보 / 원장·디자이너 소개 / 매장 이야기)을 써서 올리는 기능입니다.

왜 하나 — 입점사가 콘텐츠를 직접 생산 → 회사 운영 부담 없이 매장 신뢰도·검색 노출이 올라가고 예약·구매로 연결됩니다.
안 하면 — 매장 페이지는 가격·사진 위주로 빈약하게 유지되고, 읽을거리는 회사가 직접 만드는 매거진에만 의존하게 됩니다.
※ 필수 기능은 아니며 ‘성장 기회’ 성격입니다.
💬 회신은 번호로 편하게 주세요. 예) “1번 법무 확인 중 / 2번 OK / 6번은 분리 동의”

※ 모두 기획 담당 제안이며 확정 전입니다. 특히 1번(법무)이 전제 — 결과에 따라 운영 방식이 바뀔 수 있습니다.

⚖️ 법무 최우선 · 전제
1

칼럼을 법적으로 ‘광고’로 보는가? 입점사가 광고성 글을 올렸을 때 책임은 어디까지 지는가?

‘광고’로 판정되면 사전심의 의무가 생겨 ‘즉시 게시’가 위법이 됩니다. 또 시스템이 못 막는 맥락성 광고(예: “지금 예약 시 특별가”)를 입점사가 올리면 책임이 플랫폼에 올 수 있습니다. 나머지 모든 결정의 전제입니다.

✅ 결정 — 정보성으로 운영. 단 게시 텍스트도 의료광고 제재 대상인지 + 가이드라인은 법무 확인 필요(잔여).
💼 경영 정책 · 리스크 · 비용
2

사람이 미리 검사하지 않고 바로 게시해도 되는가?

검수 인력을 두지 않는 대신, 위반 글이 내려지기 전까지 일시 노출될 위험을 회사가 감수하게 됩니다. 금지어 검수는 두지 않고, 대신 ①면책조항 강화 ②칼럼 등록 시 유의사항 안내 ③본인 책임 확인 모달로 보완합니다.

✅ 결정 — 즉시 게시 수용. 금지어 단어검수(검출 시 차단)도 하기로(위 '검수 안 함'에서 변경) + 면책 3종도 함께 운영. 금지어 사전은 어드민이 언어별 키워드 등록.
3

작성 권한을 ‘어드민이 매장별로 켜고 끄는’ 방식으로 할까?

등급제가 아니라, 허용한 매장만 칼럼을 쓸 수 있게 하는 방식입니다. 이걸로 충분한지 확인이 필요합니다.

✅ 결정 — on/off로 개발하되 기본 ON(입점 즉시 작성 가능, 문제 시 off).
4

권한을 거둘 때 기존 글을 ‘삭제’가 아니라 ‘숨김’으로 처리할까?

삭제하면 검색 노출·데이터가 영구 손실되고 되돌릴 수 없습니다. 숨김은 고객에게 안 보이게 하되 데이터는 남깁니다.

기획 권고 — 숨김
✅ 결정 — 숨김(삭제 아님). 게시글 단위로 어드민이 숨김/삭제, 호스트도 자기 글 삭제(복구불가 모달)·숨김 가능. 어드민 작성 기능은 없음.
🎨 서비스 방향 기획 · 디자인
5

회사 매거진과 칼럼을 따로 노출할까?

같이 노출하면 입점사 글의 품질 편차가 회사 브랜드·검색 평판에까지 번질 수 있습니다.

기획 권고 — 분리
✅ 결정 — 속성이 달라 개념적으로 분리. 단 UI는 매거진 차용·디벨롭. (매거진 섹션명 'K-Beauty Magazine'으로 조정 협의)
6

고객이 칼럼을 어디로 들어와 보게 할까?

예) 마이페이지에 ‘칼럼’ 메뉴 추가 / 메인 화면에 칼럼 영역 추가 / 칼럼만 모아 보여주는 페이지 추가 중에서 선택.
