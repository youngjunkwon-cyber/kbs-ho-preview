상품 예약 선행 배포 개발 전달 (v1.3)

지금의 스토어 예약에 상품을 붙여 예약하는 기능입니다. 알리페이 채널 분기보다 먼저 따로 개발·배포합니다. 이 문서와 첨부는 알리페이 작업이 들어가기 전의 화면과 동작만 다룹니다.

1. 무엇을 만드는가

화면 ID는 22개입니다. 고객 화면 6, 호스트 6, 어드민 7, 공통 처리 3입니다. 새 화면은 없고, 기존 화면에 항목을 더합니다.

  • 고객은 상품 상세의 [예약]으로 그 상품을 예약하고, 스토어 [예약]에서도 상품을 고를 수 있습니다. 고르지 않으면 지금과 같은 스토어 예약입니다

  • 호스트와 어드민은 예약 목록·상세·카드·처리 창에서 어떤 상품 예약인지 봅니다. 어드민은 예약 상세에서 유입경로(스토어 / 상품)도 봅니다

  • 어드민은 상품마다 예약 버튼을 켜고 끄고, 상품 목록·기획전에서 예약수와 예약하기 클릭수를 봅니다

  • 클리닉 스토어 만 18세 판정과 호스트 왼쪽 메뉴 묶기("문의 · 방문 예약")도 함께 나갑니다

2. 지금 동작이 바뀌는 항목

가장 먼저 봐 주세요.

  • 호스트 왼쪽 메뉴의 채팅 관리·상담 관리·예약 관리가 "문의 · 방문 예약" 하나로 묶입니다. 하위 메뉴 이름과 화면은 그대로입니다

  • 클리닉 스토어(피부과·성형외과·치과·메디컬체크)는 방문 예정일 기준 만 18세 미만이면 예약 요청이 막힙니다. 스토어 예약도 같습니다

  • 예약 설정을 끄면 스토어 예약 버튼과 상품 예약 버튼 값이 지워지지 않고 흐리게 잠깁니다. 다시 켜면 둘 다 꺼진 상태로 시작합니다

  • 호스트 상담접수에 있던 유입경로 칼럼과 필터를 뺍니다

  • 지금 알리페이 도메인은 웹 화면과 웹 버튼 값을 그대로 쓰므로, 상품 예약도 알리페이 도메인에 웹과 똑같이 보입니다

5. 핵심 규칙

예약표

  • 상품 예약은 스토어 예약과 같은 예약표를 쓰고 1건이 한 칸입니다. 시술 시간은 쓰지 않습니다

예약 버튼

  • 어드민 상품 버튼 설정에 "예약" 줄 하나를 더합니다. 다른 버튼 줄과 같은 켜고 끄는 칸 하나입니다

  • 기본 설정 상품도 예약 줄은 스토어 예약 버튼 값을 따르지 않고 상품 값을 씁니다. 기본 설정이면 잠기므로 켜려면 개별 설정으로 바꿉니다

  • 처음 값은 모든 상품 OFF입니다. 운영자가 상품마다 켭니다

  • 예약 설정이 꺼지면 잠기고 "예약설정에서 예약을 사용하면 켤 수 있습니다."가 보입니다

  • 상품 상세 버튼 조합은 지금 웹 규칙입니다. 최대 2개, 메신저 왼쪽, 남은 한 자리는 예약 > 외부링크 > 상담접수 순입니다

상품 선택

  • 상품 상세로 들어오면 상품이 고정되고, 스토어로 들어오면 "I'll decide at the store"가 기본 선택입니다

  • 고를 수 있는 상품은 예약 버튼이 켜져 있고 지금 그 언어로 노출 중인 상품입니다. 하나도 없으면 상품 영역을 두지 않습니다

  • 예약 요청 때 상품이 예약 가능한지 다시 확인합니다. 예약 후 상품은 바꿀 수 없습니다

예약에 저장하는 값

  • 예약하는 순간의 상품명·영어 상품명·가격·썸네일과 유입경로(스토어 / 상품)를 예약에 저장하고, 모든 화면이 이 값을 보여줍니다

수치

  • 예약수는 상품이 붙은 예약의 총 접수 건수(취소·수기 포함)입니다

  • 예약하기는 상품 상세 [예약]을 누른 횟수입니다

  • 스토어 문의 통계의 플랫폼 예약은 고객이 접수한 예약 전부(수기·외부 링크 제외)이고, 지금 이름 "채널구분"에 한 칸으로 넣습니다

클리닉 스토어 예약 나이

  • 방문 예정일 기준 만 18세 이상만 예약할 수 있습니다. 예약 요청과 고객의 예약 변경 때 판정하고, 상담·채팅과 매장·운영자가 대신 하는 예약은 막지 않습니다

발송

  • 상품 예약은 상품명 줄 하나가 더해진 템플릿으로 보냅니다. 스토어 알림톡에는 영어 상품명을 함께 넣습니다(상품 그룹화 뒤부터)

6. 배포

  • 상품 예약, 클리닉 만 18세 판정, 호스트 메뉴 묶기를 함께 배포합니다. 알리페이 채널 분기 배포와는 별개이고 그보다 먼저입니다

  • 배포 때 모든 상품의 예약 줄은 OFF입니다. 배포 전 예약은 "스토어 예약", 유입경로 "-"로 보입니다

  • 배포 전에 끝낼 일: 이용약관 예약 조항에 클리닉 나이 기준 게시(법무), 클리닉 알림 창 중국어(간체·번체) 문구(기획), 상품 예약 알림톡 카카오 심사 등록(기획), 이메일 5개 언어 항목 이름 번역 검수(기획), 고객 화면 새 문구 6개 언어 번역(기획), 알림톡·문자 상품명 최대 길이(기획, 카카오 심사 때)

7. 이번 범위가 아닌 것

  • 알리페이 채널 분기의 화면과 동작(유입 채널, 버튼 표의 알리페이 칸, 알리페이 회원 예약과 문자). 알리페이 작업 때 상품 예약에 더해지는 것은 PRD 부록 B에 있습니다

  • 시술 시간에 따른 여러 칸 예약, 상품 옵션 선택, 구글 예약 연동, 입점사의 상품 예약 버튼 제어, 예약 목록 엑셀 다운로드
