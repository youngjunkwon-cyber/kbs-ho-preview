# 상품 예약 발송 템플릿 초안

기준 문서: 상품예약_PRD_v0.63_20261109 (7. 발송). 상품 예약 선행 배포 때는 알리페이 회원 문자를 쓰지 않습니다(상품예약_선행배포_PRD_v1.11_20261109 7장).

상품이 붙은 예약은 아래 상품 예약용 템플릿으로 보냅니다. 스토어 예약(상품 없는 예약)은 기존 템플릿을 그대로 씁니다. 기존 템플릿과 달라지는 것은 상품 줄 하나입니다.

## 공통 규칙

- 상품 줄은 방문 일시 줄 바로 아래에 둡니다. 일시 줄이 둘인 유형(변경 요청 · 변경 완료, 이메일 변경 · 거절)은 두 줄 다음에 둡니다.
- 상품명은 예약에 저장해 둔 값(고객이 예약한 언어)을 씁니다.
- 새 변수는 `#{product_name}` 하나입니다.
- 스토어 담당자 알림톡(1)만 영어 상품명을 함께 넣습니다. 고객 이메일·문자는 예약 언어 상품명만 씁니다.
- 버튼, 시간 표기(KST), 나머지 줄은 채널마다 기존 스토어 예약 템플릿과 같습니다.
  - 스토어 담당자 알림톡: `예약알림톡_템플릿_초안.md`
  - 웹 고객 이메일 · 문자: 스토어 예약 기능정의서의 Figma "5 · 발송 템플릿" 페이지(이메일 5종, SMS 5종)
  - 알리페이 회원 문자: 알리페이 PRD 12장(알리페이 작업 때부터. 선행 배포 범위가 아닙니다)

## 1. 스토어 담당자 알림톡 (5종)

버튼은 기존과 같은 `예약 상세 보기` 하나입니다.

`#{product_name}`에 들어가는 값:
- 영어가 아닌 언어로 예약했고 같은 상품의 영어 상품이 있으면 "예약 언어 상품명 (영어 상품명)". 예: `Abijou ボトックス (Abijou Botox)`
- 영어로 예약했거나 영어 상품이 없으면 예약 언어 상품명만. 예: `Abijou Botox`
- "같은 상품의 영어 상품"은 상품 그룹화로 묶인 영어 상품입니다. 그룹화 전에는 예약 언어 상품명만 들어갑니다.

### 01-P. 새 예약 (상품)

```text
새 예약이 접수됐어요.

방문 예정: #{visit_datetime}
예약 상품: #{product_name}
고객: #{customer_name}
예약번호: #{booking_number}

예약 내용을 확인해 주세요.
```

### 02-P. 미확인 예약 (상품)

```text
아직 확인하지 않은 예약이 있어요.

방문 예정: #{visit_datetime}
예약 상품: #{product_name}
고객: #{customer_name}
예약번호: #{booking_number}

예약 상세를 열어 내용을 확인해 주세요.
```

### 03-P. 예약 취소 (상품)

```text
예약이 취소됐어요.

방문 예정: #{visit_datetime}
예약 상품: #{product_name}
고객: #{customer_name}
취소한 사람: #{cancelled_by}
예약번호: #{booking_number}

예약 상세에서 취소 내용을 확인해 주세요.
```

### 04-P. 예약 시간 변경 요청 (상품)

```text
고객이 예약 시간 변경을 요청했어요.

기존 방문: #{visit_datetime}
변경 요청: #{requested_visit_datetime}
예약 상품: #{product_name}
고객: #{customer_name}
예약번호: #{booking_number}

예약 상세에서 수락 또는 거절을 선택해 주세요.
```

### 05-P. 예약 시간 변경 완료 (상품)

```text
예약 시간 변경이 완료됐어요.

기존 방문: #{previous_visit_datetime}
변경된 방문: #{visit_datetime}
예약 상품: #{product_name}
고객: #{customer_name}
예약번호: #{booking_number}

변경된 방문 일시를 확인해 주세요.
```

### 카카오 템플릿 등록 (2026-10-20 완료)

- 5종 모두 새 템플릿으로 등록했습니다(기존 템플릿 수정이 아님). 템플릿 코드는 기존 코드 끝에 `_PD`를 붙였고(예: `PRD_HOST_BKG_NEW_PD`, `STG_HOST_BKG_NEW_PD`), 이름에 "상품"을 넣었습니다. STG·PROD 각 5종입니다.
- `#{product_name}`에는 영어 상품명이 함께 들어갈 수 있어 길어질 수 있습니다. 상품명이 길면 알림톡 본문이 잘릴 수 있습니다.

## 2. 고객 이메일 (6개 언어, 5종: 확정 / 리마인더 / 취소 / 변경 / 거절)

받는 사람: 웹 고객과, 알리페이 도메인에서 비로그인으로 예약한 고객(선행 배포 때 전부, 알리페이 작업 뒤에는 진입 관문을 끈 동안. PRD 7)

본문 표의 방문 일시 줄 아래에 "상품" 한 줄을 더합니다. 새로 번역할 말은 항목 이름 하나입니다.

| 언어 | 항목 이름 | 예시 |
|---|---|---|
| 영어 | Product | Product: Abijou Botox |
| 중국어(간체) | 商品 | 商品：Abijou 肉毒杆菌 |
| 중국어(번체) | 商品 | 商品：Abijou 肉毒桿菌 |
| 일본어 | メニュー | メニュー：Abijou ボトックス |
| 인도네시아어 | Layanan | Layanan: Abijou Botox |
| 몽골어 | Үйлчилгээ | Үйлчилгээ: Abijou Botox |

- 영어는 FO 화면 문구("Product")와 같게 둡니다.
- 나머지 5개 언어는 고객 화면 번역(상품 예약 번역 문구 전달 위키 1-1)과 같은 말입니다. 일본어 "メニュー", 중국어 "商品"은 지금 고객 화면 스토어 상세에서 쓰는 말에 맞췄습니다(2026-11-05 확정).

## 3. 고객 문자

- 웹 고객 문자(확정 / 리마인더 / 취소 / 변경 / 거절): 방문 일시 아래에 상품 줄 하나를 더합니다.
  - 문자 언어는 지금 스토어 예약 문자와 같습니다(스토어 예약 PRD: 한글 우선, 다국어는 후속). 한글 문자의 항목 이름은 "상품"입니다. 예: "상품: Abijou Botox"
  - 상품명은 예약 언어 그대로입니다.
  - 문자가 다국어로 나오면 2장 이메일 표의 언어별 항목 이름을 씁니다.
  - 지금 스토어 예약 문자가 나가는 유형마다 상품 줄을 더합니다(PRD 7).
- 알리페이 회원 문자(예약 확인 / 변경 / 취소 / 거절 / 방문 하루 전, 알리페이 작업 때부터): 방문 일시 아래에 상품 줄 하나를 더합니다.
  - 항목 이름은 회원의 지금 언어를 따르고, 2장 이메일 표와 같은 이름을 씁니다.
    - 중국어(간체): 预约项目
    - 중국어(번체): 預約項目
    - 영어: Product
  - 상품명은 예약 언어 그대로입니다.
- 문자는 길이 제한이 있어 상품명이 길면 LMS로 넘어갈 수 있습니다.
