# 상품 예약 고객 화면 번역 문구 전달

상품 예약 배포(2026-11-12) 때 고객 화면(FO)과 이메일에 새로 들어가는 문구의 언어별 번역입니다. 영어가 원문이고, 나머지 5개 언어는 아래 문구를 그대로 넣어 주세요. 화면 모양은 디자인 확정본(Figma "디자인(최종)" 페이지)을 따르고, 디자인의 한국어 문구는 뜻을 맞춘 참고용입니다.

- 언어: 영어(원문), 일본어, 중국어(간체), 중국어(번체), 인도네시아어, 몽골어
- 상품 이름, 스토어 이름, 날짜·시간, 가격은 번역하지 않고 지금처럼 데이터 값을 그대로 넣습니다.
- 지금 라이브에 이미 있는 문구(아래 "라이브 문구 그대로" 표시)는 라이브의 언어별 번역을 그대로 씁니다.

## 9. 참고

- 상품을 부르는 말은 지금 고객 화면에 맞췄습니다. 일본어는 "メニュー"(스토어 상세 "施術メニュー"), 중국어는 "商品"(스토어 상세 "代表商品")입니다. 화면과 이메일이 같은 말을 씁니다.
- 스토어를 부르는 말도 지금 고객 화면 스토어 상세에 맞췄습니다. 일본어 店舗, 중국어(간체) 门店, 중국어(번체) 機構, 인도네시아어 Toko, 몽골어 Дэлгүүр입니다.
- 화면 위치와 동작은 상품 예약 선행 배포 PRD v1.12의 5.2·5.5·5.11·5.13과 개발 전달 위키를 따릅니다.
