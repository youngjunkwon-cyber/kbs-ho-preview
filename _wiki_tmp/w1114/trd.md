# 상품 상세·스토어 상세 번역 문구 전달

고객 화면(FO)의 상품 상세, 스토어 상세, 비포애프터, 스토어 리뷰 페이지, 리뷰 작성 화면이 디자인 확정본(Figma "디자인(최종)" 페이지)으로 바뀌면서 새로 들어가는 문구의 언어별 번역입니다. 영어가 원문이고, 나머지 5개 언어는 아래 문구를 그대로 넣어 주세요. 지금 라이브에 이미 있는 문구(2장)는 라이브의 언어별 번역을 그대로 씁니다. 디자인의 한국어 문구는 뜻을 맞춘 참고용입니다.

- 언어: 영어(원문), 일본어, 중국어(간체), 중국어(번체), 인도네시아어, 몽골어
- 상품 이름, 스토어 이름, 가격, 별점, 리뷰 본문, 스토어 키워드·태그, 인스타그램 게시물 글은 번역하지 않고 지금처럼 데이터 값을 그대로 넣습니다.
- {storeName}, {productName} 자리에는 스토어 이름, 상품 이름이 들어갑니다.

## 3. 참고

- 상품을 부르는 말과 스토어를 부르는 말은 지난 번역 전달(상품예약_번역전달_20261110.md 9장)과 같습니다.
  - 상품: 일본어 メニュー, 중국어(간체) 商品, 중국어(번체) 商品, 인도네시아어 Layanan, 몽골어 Үйлчилгээ
  - 스토어: 일본어 店舗, 중국어(간체) 门店, 중국어(번체) 機構, 인도네시아어 Toko, 몽골어 Дэлгүүр
- 리뷰를 부르는 말은 라이브에 맞췄습니다. 일본어는 구글 리뷰·리뷰 목록 링크에 レビュー, K-Beauty Station에 남기는 후기에 口コミ를 씁니다. 중국어(번체)는 評價, 인도네시아어는 Ulasan, 몽골어는 сэтгэгдэл입니다.
- 전후 사진을 부르는 말은 라이브 비포애프터 문구(store_detail.before_after.detail_header_title)의 언어별 번역에 맞췄습니다.
- 라이브 키는 2026-11-09 라이브 고객 화면(k-beautystation.com)의 영어 메시지에서 확인했습니다.
- 화면 위치와 동작은 상품 예약 선행 배포 PRD v1.14의 5.17을 따릅니다.

- 스토어 리뷰 페이지 제목과 리뷰 작성 화면의 입력 안내는 지금 라이브 그대로입니다(PRD 5.17, 리뷰 페이지·작성 화면은 바꾸지 않음). 디자인의 "스토어 리뷰", "500자" 글자는 넣지 않습니다.
